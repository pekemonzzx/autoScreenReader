# 运行时与声库：这两个目录不在仓库里

程序要跑起来需要**三样东西**，但仓库里只有第一样：

| # | 东西 | 在哪 | 体积 | 为什么不在仓库 |
| :-- | :--- | :--- | ---: | :--- |
| 1 | **主程序** | 仓库源码 / Release 里的 `AutoScreenReader-x.y.z-portable.zip` | 142 MB | ✅ 在 |
| 2 | **TTS 推理运行时** | `<程序目录>\gsv\` | **约 9 GB** | 第三方内容（GPT-SoVITS 整合包），GitHub 装不下 |
| 3 | **声库（音色）** | `<程序目录>\voices\<名字>\` | 每个约 300 MB | 单文件超 100 MB 被 GitHub 硬拒；且是真人声音克隆结果 |

本文讲清楚：**这两个目录必须长什么样、从哪弄、怎么验证装对了。**

---

## 一、TTS 推理运行时（`gsv/`）

### 1.1 它是什么

程序本身**不含** PyTorch、CUDA、GPT-SoVITS 这些重家伙。
推理时它会启动一个本地 HTTP 服务（默认 `127.0.0.1:9880`），把要念的句子 POST 过去，
拿回 WAV 再播放。那个服务就是 `gsv\` 里的东西。

> 好处：主程序只有 142 MB；换模型/换显卡驱动不用重装程序。

### 1.2 目录结构（必须长这样）

```
<程序目录>\
└─ gsv\
   ├─ api_v2.py                  推理服务入口（FastAPI）
   ├─ config.py                  GPT-SoVITS 配置
   ├─ .runtime_installed.json    安装标记 —— 少了它程序会认为"没装运行时"
   ├─ GPT_SoVITS\                模型代码 + 预训练模型（约 2.5 GB）
   │   ├─ pretrained_models\     bert / hubert / sv / s2G / s2D
   │   ├─ configs\
   │   └─ prepare_datasets\      训练用的脚本
   ├─ runtime\                   内嵌 Python 3.9 + torch（约 6.4 GB）
   │   ├─ python.exe             ← 程序就是用它启动服务的
   │   └─ Lib\site-packages\
   ├─ tools\                     GPT-SoVITS 自带工具（uvr5 人声分离 / asr 等）
   ├─ GPT_weights_v2ProPlus\     训练产出的 GPT 权重（可以先空着）
   └─ SoVITS_weights_v2ProPlus\  训练产出的 SoVITS 权重（可以先空着）
```

**关键点**：

- `runtime\python.exe` 是**内嵌的隔离 Python**，不要用系统 Python 代替；
- `GPT_SoVITS\pretrained_models\` 里的预训练模型**必须齐**，否则服务起不来；
- 这个目录在**程序目录内**，不是系统全局安装，删掉就等于卸载。

### 1.3 怎么弄到它（三种方式，任选）

#### 方式 A：在线清单下载（推荐给最终用户）

程序首次启动发现没运行时，会**自动弹出安装窗口**，在里面填清单地址就行。

命令行等价：

```bat
读屏台.exe --runtime install --manifest https://<你的地址>/manifest.json
```

清单（`manifest.json`）格式：

```json
{
  "runtime_version": "1",
  "base_url": "https://<你的地址>/parts/",
  "total_size": 9663676416,
  "parts": [
    { "name": "gsv.part01.zip", "size": 2147483648, "sha256": "..." },
    { "name": "gsv.part02.zip", "size": 2147483648, "sha256": "..." }
  ],
  "note": "GPT-SoVITS v2ProPlus 运行时"
}
```

> 支持断点续传；分卷大小默认 2 GB（`--part-mb` 可改）。

#### 方式 B：本地文件夹 / zip（离线，最省事）

```bat
读屏台.exe --runtime install --from D:\下载\gsv
读屏台.exe --runtime install --from D:\下载\gsv.zip
```

`--from` 指向的目录里应当直接是 `api_v2.py`、`runtime\`、`GPT_SoVITS\` 这一层
（**不是**再套一层 `gsv\`）。

#### 方式 C：自己从 GPT-SoVITS 整合包搭

1. 下载 **GPT-SoVITS v2ProPlus** 整合包（官方发布，约 9 GB）
2. 解压，把里面的内容整理成上面 1.2 的结构
3. 确认 `runtime\python.exe` 存在
4. 跑 `读屏台.exe --runtime configure` 修掉整合包里**硬编码的打包者路径**
   （`users.pth` 里会写死作者机器的绝对路径，换个位置就 `ModuleNotFoundError`）

> 为什么必须跑 `configure`：`runtime\Lib\site-packages\users.pth` 里存着
> `D:\原打包者\...` 这种绝对路径，不解压到同一位置就找不到 `text` / `tools` 模块。

### 1.4 验证装对了

```bat
读屏台.exe --runtime status      :: 是否已安装、装在哪、多大
读屏台.exe --runtime verify      :: 轻量自检（关键文件在不在）
读屏台.exe --runtime doctor      :: 环境体检（权限 / 候选位置，排障用）
```

界面上也有对应反馈：状态栏右侧的 **语音服务状态灯**（绿=就绪 / 黄=启动中 / 红=没运行），
点红灯可以手动启动服务。

## 二、声库（`voices/<名字>/`）

### 2.1 它是什么

一个声库 = **一个音色**。里面装的是微调后的权重 + 一条参考音频，
程序拿它去做 zero-shot / few-shot 语音克隆。

**声库可以独立分发给别人**，不需要重训。

### 2.2 目录结构（必须长这样）

```
<程序目录>\
└─ voices\
   └─ voice01\                  ← 目录名 = 声库名（建议用 ASCII）
      ├─ voice.json             ★ 元数据（必填，见 2.3）
      ├─ ref.wav                ★ 参考音频（必填，3~10 秒干净人声）
      ├─ weights\               ★ 微调权重（必填）
      │   ├─ voice01-e12.ckpt         GPT 权重
      │   └─ voice01_e8_s152.pth      SoVITS 权重
      ├─ train.yaml             训练配置（`voice new` 自动生成）
      ├─ train.list             训练标注（训练后保留，便于复现）
      ├─ tts_infer.yaml         推理配置（程序自动生成，别手改）
      └─ README.md              备注（可选）
```

### 2.3 `voice.json` 字段说明

```json
{
  "name": "voice01",
  "display_name": "示例音色",
  "version": "v2ProPlus",

  "ref_audio": "ref.wav",
  "prompt_text": "参考音频里**实际说的那句话**",

  "gpt_weights": "weights/voice01-e12.ckpt",
  "sovits_weights": "weights/voice01_e8_s152.pth",

  "api_url": "http://127.0.0.1:9880",
  "speed_factor": 1.0,

  "train": {
    "version": "v2ProPlus",
    "list_path": "train.list",
    "s2_batch": 6,  "s2_epoch": 8,
    "s1_batch": 8,  "s1_epoch": 15,
    "save_every": 4, "fp16": true
  },
  "created": "2026-01-01 00:00:00",
  "source": "",
  "notes": ""
}
```

**三个最容易踩的点**：

| 字段 | 要求 | 踩错会怎样 |
| :--- | :--- | :--- |
| `prompt_text` | **必须和 `ref.wav` 里实际说的话一字不差** | 音色会跑偏、念得像外国口音 |
| `gpt_weights` / `sovits_weights` | 相对**声库目录**的路径 | 找不到权重，卡片全是"失败" |
| `name` | 和目录名一致，建议 ASCII | 文件名里带中文时某些脚本会挂 |

### 2.4 怎么弄到一个声库（三种方式）

#### 方式 A：装别人打包好的 `.voicepack.zip`（最快）

```bat
读屏台.exe --voice install voice01.voicepack.zip
```

也可以**直接把 zip 解压到 `voices\` 目录下**，程序会自动识别。

装完验证：

```bat
读屏台.exe --voice list        :: 列出所有声库
读屏台.exe --voice scan        :: 扫描并校验手工放入的声库
读屏台.exe --voice verify voice01
```

#### 方式 B：自己训练（从零做一个音色）

完整流程在 **[`train/README.md`](../train/README.md)**，一句话版本：

```powershell
python train\run.py --input "<你的录音>" --work "<工作目录>" --name voice01
```

会依次做：素材体检 → 人声分离 → 切片 → ASR 标注 → **人工校对（必须人来做）** → 训练 → 打包。

**素材要求**（很重要，决定上限）：

| 项 | 建议 |
| :--- | :--- |
| 时长 | 3~10 分钟纯净人声（< 3 分钟效果明显差） |
| 采样率 | **48 kHz 优先**（16 kHz 素材的高频细节永久丢失，擦音会糊） |
| 内容 | 一个人、无背景音乐、无回声、情绪平稳 |
| 格式 | m4a / wav / mp4 都行（内部会转） |

**耗时参考**（RTX 4080 SUPER，54 条 / 约 3 分钟语料，默认 8+15 epoch）：约 **3 分钟**。

#### 方式 C：用别人训练好的权重，自己建档案

适用于：拿到了 `.pth` + `.ckpt`，但没有 `.voicepack.zip`。

```powershell
# 1. 建档案
读屏台.exe --voice new voice01 --list train.list --wav-dir <切片目录>

# 2. 把权重放进 voices\voice01\weights\
#    （文件名前缀要和声库名一致）

# 3. 指定参考音频（文本必须对得上音频）
读屏台.exe --voice set-ref voice01 --wav ref.wav --text "参考音频里说的话"

# 4. 刷新权重指向 + 生成推理配置
读屏台.exe --voice refresh voice01

# 5. 自检 + 切换
读屏台.exe --voice verify voice01
读屏台.exe --voice use voice01
```

### 2.5 分发自己的声库

```bat
读屏台.exe --voice pack voice01
:: 生成 voices\_packs\voice01.voicepack.zip
```

**分发前务必确认**：参考音频和权重里是**你本人**的声音，或者你已经获得本人同意。
声音克隆是可以被滥用的，公开分发别人的声音样本有法律风险。

## 三、装完之后应该是什么样

```
<程序目录>\
├─ 读屏台.exe
├─ _internal\                    程序本体（PyInstaller）
├─ start.bat  run_console.bat
├─ README.txt
├─ data\
│   ├─ config.json               程序配置（声库名、语速、区域…）
│   └─ screenreader.log          运行日志（排障先看这个）
├─ gsv\                          ★ 运行时（约 9 GB，需自行安装）
└─ voices\                       ★ 声库（每套约 300 MB，需自行安装）
    └─ voice01\
```

**自检一键命令**：

```bat
读屏台.exe --version             :: 版本号
读屏台.exe --runtime status      :: 运行时状态
读屏台.exe --runtime verify      :: 运行时完整性
读屏台.exe --voice list          :: 声库列表
```

## 四、常见错误对照

| 现象 | 原因 | 怎么办 |
| :--- | :--- | :--- |
| 启动就弹"没装运行时" | `gsv\` 不存在或缺 `.runtime_installed.json` | `--runtime install --from <目录>` |
| 服务启动后立刻退出 | `users.pth` 里是别人的绝对路径 | `--runtime configure` |
| `ModuleNotFoundError: No module named 'text'` | 同上（`users.pth` 没修） | 同上 |
| 卡片一直"合成中" | 语音服务没起来 | 看状态灯；点红灯启动；`--runtime status` |
| 卡片全"失败" | 没装声库 / 权重路径不对 | `--voice list`、`--voice verify <名字>` |
| 念出来像外国人口音 | `prompt_text` 和参考音频对不上 | `--voice set-ref` 重填，文本逐字对 |
| 声音很闷、擦音糊 | 训练素材是 16 kHz | 换 48 kHz 素材重训（素材决定上限） |
