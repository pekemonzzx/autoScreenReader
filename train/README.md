# 声学模型训练流程（语料 → 标注 → 训练 → 打包）

这个文件夹是**从零做一个新声库**的完整流程，每一步都有脚本。

> 适用：GPT-SoVITS **v2ProPlus** 的 few-shot 微调（十几分钟语料就够）。
> 本机已验证跑通，全流程约 **30~60 分钟**（不含人工标注时间）。

## ① 素材体检 —— 别跳过这一步

```powershell
.\.venv\Scripts\python.exe train\00_check_source.py "D:\path\to\素材.m4a"
```

它会告诉你：

| 输出 | 含义 |
| :--- | :--- |
| 采样率 | **< 44.1kHz 就别做了**，擦了的高频练不回来 |
| 8–11 kHz 能量 | **低于 -55 dB 说明高频没了**，念出来擦音会闷 |
| 时长 | 建议 10~30 分钟素材（分离切片后剩一半左右） |

**为什么这一步最重要**：本项目最大的一次音质提升就是换素材（16kHz → 48kHz），
擦音频段相差 **+23 dB**，ASR 回读从「基本杀」变成「剧本杀」。
**信息在源头没了，练一万轮也变不出来。**

## ② 造语料

```powershell
.\.venv\Scripts\python.exe train\01_make_corpus.py `
    --input "D:\path\to\素材.m4a" `
    --work  "D:\GPT-SoVITS\work\我的声库" `
    --auto-split
```

做四件事：抽音轨（**保持 44.1kHz**）→ UVR5 去背景 → 切片 → FunASR 标注。

产物：

```
<work>/00_raw/       抽出来的音轨
<work>/01_vocal/     去背景后的人声
<work>/02_sliced/    切片（3~10 秒）
<work>/03_list/      自动标注
<work>/train.list    合并后的完整列表
```

### 大素材一定要加 `--auto-split`

UVR5 会把**整段音频**读进内存（重采样成 44.1kHz 立体声 float64），
一份就约 **1 GB / 25 分钟**。2 小时的素材要 **20 GB** —— 16GB 机器必崩。

`--auto-split` 会读你的可用内存，自动算出切几段：

```
素材时长 120.3 分钟
可用内存 6.3 GB
整段需要 20.0 GB，内存不够 —— 切成 6 段：
     0:00 -  20:00    20.0 分钟  峰值约 4.2 GB
    20:00 -  40:00    20.0 分钟  峰值约 4.2 GB
    ……
```

**为什么切了就不占内存**：每一段是**独立文件**，UVR5 逐个处理 ——
峰值只和**最长的那段**有关，不是总和。

**代价**：段边界可能切断一个词。边界附近会多出几条废片，
标注时删掉就行（本来就该逐条听）。

> 内存够的话不会切 —— 不切质量最好。25 分钟素材 + 8.9 GB 可用就整段跑。

### 手工指定时间段

要精确控制就用 `--segments`（逗号分隔，可多段）：

```powershell
# 只取 0:00-24:40
--segments "0:00-24:40"

# 分成四段（每段独立处理）
--segments "0:00-30:00,30:00-1:00:00,1:00:00-1:30:00,1:30:00-2:00:00"
```

时间格式 `分:秒` 或 `时:分:秒` 都行。

## ③ 机械过滤

```powershell
.\.venv\Scripts\python.exe train\02_filter_list.py `
    --list "D:\GPT-SoVITS\work\我的声库\train.list" `
    --out  "data\我的声库_train_clean.list" `
    --wav-dir "D:\GPT-SoVITS\work\我的声库\02_sliced"
```

按**时长**和**语速**筛：

- 太短（< 1 秒）、太长（> 12 秒）→ 剔
- 语速 > 9 字/秒 → 基本是 ASR 幻觉，剔
- 语速 < 1.2 字/秒且字数 > 12 → 大半是静音，剔

> **注意**：不要用"字数上限"来筛。以前默认卡 25 字，白白扔掉了 25% 的
> 正常连续语音（实测那些 7~9 秒、5 字/秒 的样本对学韵律反而更有用）。

## ④ 人工标注 ★ 不能跳

```powershell
.\.venv\Scripts\python.exe train\03_annotate.py --list "data\我的声库_train_clean.list"
```

浏览器打开 **http://127.0.0.1:9871**，逐条：

1. **听**这一句在说什么
2. **改**文本（ASR 会听错同音字、漏气口）
3. 听不清 / 有杂音 / 有 BGM 残留 → **删掉这一条**
4. 每条都要点 **`Submit Text`** 才落盘（不点会回滚！）

> 校对质量**直接决定**最终音色。这一步省下来的时间，后面会加倍还回去。

## ⑤ 训练前校验

```powershell
.\.venv\Scripts\python.exe train\04_verify_list.py --list "data\我的声库_train_clean.list"
```

检查四件事：

| 检查 | 为什么 |
| :--- | :--- |
| 每行格式合法、音频存在、32kHz 单声道 | 格式不对训练会报奇怪的错 |
| 没有重复引用同一个 wav | 重复会让某句话被过度学习 |
| **语速合理** | **错位最灵敏的信号** —— 文本和音频一旦对不上，语速立刻变得离谱 |
| 文本非空、无残留标记 | 空文本会让对齐失败 |

还会跟 `.raw` 备份对比，告诉你删了哪些、改了多少处。

## ⑥ 训练

```powershell
.\.venv\Scripts\python.exe train\05_train_voice.py `
    --name 我的声库 `
    --list "data\我的声库_train_clean.list" `
    --wav-dir "D:\GPT-SoVITS\work\我的声库\02_sliced" `
    --calm
```

依次做：

1. **建档案** `voices\<名字>\`
2. **挑参考音频** —— `--calm` 会按"叙述型/平和度"评分挑
   （音高波动 + 能量波动 + 感叹号扣分）
3. **训练**：1ABC 预处理 → SoVITS → GPT（约 3~5 分钟）
4. **刷新权重指向** + **写推理配置**
5. **自检**（权重、参考音频、配置是否齐全）

产物：

```
D:\GPT-SoVITS\GPT-SoVITS-v2pro-20250604\
    SoVITS_weights_v2ProPlus\我的声库_e8_s256.pth
    GPT_weights_v2ProPlus\我的声库-e12.ckpt
voices\我的声库\           ← 自包含档案
```

### 参考音频为什么单独挑

GPT-SoVITS 的**音色、情绪、语速几乎全部来自参考音频**。实测换一条：

| | 情绪高的参考 | 平和叙述型 |
| :--- | ---: | ---: |
| 音高波动 | 0.196 | **0.140（−29%）** |
| 能量波动 | 0.81 | **0.58（−28%）** |

而且**不用重训**，换一条就立刻生效 —— 这是性价比最高的杠杆。

## 五个必须记住的坑

### 1. 采样率是天花板，练不回来
`-ar 16000` 会把 8kHz 以上全砍掉，而 `ch/zh/sh/c/z/s` 的区分特征在 4~10kHz。
`00_check_source.py` 就是用来在开始前挡住这个的。

### 2. 文本-音频错位是**静默**的
不报错，只是某个字永远念不对。`04_verify_list.py` 用**语速**当探针，
错位时语速会立刻变得离谱。

### 3. 参考音频的情绪会被一起克隆
随手拿一条情绪最高的片段当参考，之后念什么都带那股劲儿。用 `--calm`。

### 4. 声库包**不含** `tts_infer.yaml`
它是**本机生成**的（里面写死了本机路径），打进去没意义。
安装时程序会自动重建 —— 如果你手动解压声库包，记得跑一次
`读屏台.exe --voice refresh <名字>`。

### 5. `users.pth` 会写死打包者的路径
换机器后模块导入失败。`build_runtime.py` 里有 `repair_users_pth()` 专门修这个，
装运行时的时候会自动跑。

## 常见问题

| 现象 | 原因 / 处理 |
| :--- | :--- |
| UVR5 报 `_ArrayMemoryError` | 内存不够。关浏览器/游戏；或 `--segments` 把素材截短 |
| SoVITS 训练 `CUDA out of memory` | 显存被游戏占了。关游戏，或把 `--s2-batch` 从 6 降到 4 |
| 训练报 `No module named screenreader` | 用了错的 Python。必须用**整合包内嵌**的那个（脚本已处理） |
| 合成每句都 400 | 声库没选中，或 `tts_infer.yaml` 没生成 → 跑 `voice refresh` |
| 前几个字有怪音 | 参考音频和参考文本配串了 → 跑 `04_verify_list` 的思路核对 |
| 擦音发闷 | 素材高频不够。回第 ① 步体检 |
| 训练完找不到权重 | 看 `SoVITS_weights_v2ProPlus\` / `GPT_weights_v2ProPlus\` |
